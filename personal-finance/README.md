# Personal Finance — Google Apps Script

ซอร์สระบบรายรับ–รายจ่าย รุ่น 46 ณ วันที่ 15 ตุลาคม 2569

หน้าเว็บหลักยังอยู่ที่ [FinanceAAA](https://wonbinaaa.github.io/FinanceAAA/) และฝัง Google Apps Script deployment เดิม โฟลเดอร์นี้เก็บซอร์สสำหรับดูแลและสำรองงาน ไม่ใช่เว็บ HTML ที่เปิดใช้งานแยกได้โดยตรง เพราะใช้ `google.script.run` และ template ของ Apps Script

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| Code.gs | ฐานข้อมูล Google Sheets และกฎคำนวณการเงิน |
| Index.html | หน้าเว็บและฟอร์ม |
| CSS.html | รูปแบบหน้าจอและรองรับมือถือ |
| JavaScript.html | การโต้ตอบและเรียก backend |
| appsscript.json | Apps Script manifest และเขตเวลา Asia/Bangkok |
| Finance.test.js | ทดสอบด้วย Google Sheets จำลองในเครื่อง |
| line-relay.js | ตัวกลาง HTTPS สำหรับ LINE webhook |
| LINE-PLAN.md / LINE-SETUP.md | คำสั่งและวิธีตั้งค่า LINE |

## ตั้งค่า Apps Script

1. เพิ่มไฟล์หลักสี่ไฟล์และ manifest ในโปรเจกต์ Google Apps Script ชื่อไฟล์ HTML ต้องตรงกับต้นฉบับ
2. ตั้ง Script Property `FINANCE_SPREADSHEET_ID` เป็นรหัส Google Sheets ของคุณ ซอร์สสาธารณะไม่เก็บรหัสชีตจริง
3. โค้ดนี้ใช้โครงสร้างฐานข้อมูลของระบบเดิม: ผู้ใช้งาน, บัญชี, หมวดหมู่, รายการเงิน, หนี้สิน, รายการหนี้, เงินสำรองบริษัท, รายการประจำ, ตั้งค่าระบบ และประวัติการแก้ไข ไม่ได้สร้างฐานข้อมูลเริ่มต้นให้อัตโนมัติ หัวตารางอยู่แถว 1 ป้ายชื่อแถว 2 และข้อมูลเริ่มแถว 3 ดูคีย์คอลัมน์ใน fixture `schema` ของชุดทดสอบ โดยอย่านำข้อมูลจำลองไปทับฐานข้อมูลจริง
4. หากใช้ระบบที่ deploy อยู่แล้ว ให้อัปเดต deployment ID เดิมเพื่อคง URL อย่าสร้างธุรกรรมจริงเพียงเพื่อทดสอบหน้าตา

`APP_FAVICON` ใช้รูปที่เผยแพร่อยู่แล้วใน repository หลัก สำเนานี้ต่างจากไฟล์ใช้งานจริงเฉพาะการตั้งค่า Spreadsheet ID และ URL favicon ไม่ได้เปลี่ยน deployment ปัจจุบัน

## ทดสอบในเครื่อง

ใช้ Node.js 20 ขึ้นไป แล้วรันจากโฟลเดอร์นี้:

```sh
node Finance.test.js
node line-relay.test.js
```

ชุดทดสอบใช้ข้อมูลจำลองและไม่เชื่อมต่อ Google Sheets จริง

## ฟีเจอร์ปัจจุบัน

- รายรับ รายจ่ายส่วนตัว/บริษัท โอนเงิน แก้ไข และยกเลิกแบบ VOID
- เงินบริษัทล่วงหน้าแยกโปรเจกต์ จับคู่เงินคืน ย้ายเงินเหลือ และเบี้ยเลี้ยงตัวเอง/คนอื่น
- หนี้คงเหลือ ยอดจ่ายรายเดือน และรายการประจำ
- หน้าจอมือถือ การ์ดแยกสี และล็อกพื้นหลังขณะเลื่อนฟอร์ม
- ปุ่มรายการประจำที่แถบด้านบน และยอดเงินบริษัทแยกใกล้ยอดเงินจริงหน้าแรก
- ฟอร์มเงินคืนบริษัทแสดงยอดค้างคืนและรายการไม่มีโปรเจกต์ พร้อมข้อความผิดพลาดค้างในฟอร์ม และล้างผลจับคู่เก่าเมื่อเปลี่ยนจำนวนเงิน
- LINE คำสั่งข้อความมีโค้ดแล้ว ต้องตั้งค่าโฮสต์และ secrets ก่อนใช้งานจริง การอ่านสลิปยังไม่ได้เปิดใช้

## ไฟล์ที่ไม่เผยแพร่

ไม่รวมไฟล์ล็อกอิน `.clasprc.json`, `.clasp.json`, secrets, ภาพหน้าจอยอดเงินจริง, บันทึกการปรับธุรกรรม, สำเนาระยะไกล, ไฟล์แนบ หรือข้อมูลชีตจริง เก็บ secrets ไว้ใน Script Properties หรือระบบ secrets ของโฮสต์ LINE เท่านั้น
