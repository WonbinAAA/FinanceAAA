# แผนรับคำสั่งผ่าน LINE (ต่อจากเวอร์ชัน 31)

## คำสั่ง

ใช้เครื่องหมาย `|` คั่นช่อง ชื่อหมวดและบัญชีต้องตรงกับชื่อใน Sheet ที่เปิดใช้งาน (ถ้าชื่อซ้ำให้ใช้รหัส) จำนวนเงินเป็นบาท บวก และมีทศนิยมไม่เกินสองตำแหน่ง วันที่ใช้วันที่ปัจจุบันในเขตเวลา Asia/Bangkok

| คำสั่ง | ตัวอย่าง |
| --- | --- |
| รายรับ | `รับ | 1500 | เงินเดือน | กรุงไทย | งานพิเศษ` |
| รายจ่ายส่วนตัว | `จ่าย | 85.50 | ข้าวเที่ยง | เงินสด | ส่วนตัว | อาหาร` |
| รายจ่ายบริษัท | `จ่าย | 600 | ค่าน้ำมัน | กรุงไทย | บริษัท | งานลูกค้า` |
| โอนเงินตัวเอง | `โอน | 500 | กรุงไทย | เงินสด | ถอนเงิน` |
| ตรวจรายการร่าง | `ร่าง` |
| ยืนยันรายการ | `ยืนยัน TX-XXXXXXXX` |
| วิธีใช้ | `ช่วยเหลือ` |

รายการเงินคืนบริษัทใช้หมวด `เงินคืนบริษัท` และต้องมีลูกหนี้บริษัทพอจับคู่ ระบบแสดงรายการจับคู่ที่เสนอในข้อความร่าง และตรวจข้อเสนอเดิมอีกครั้งขณะยืนยัน หากยอดค้างเปลี่ยนจะไม่ยืนยันรายการนั้น

## ตัวตนและความน่าเชื่อถือ

1. ตัวกลาง Node รับ LINE webhook เป็น byte ดิบและตรวจ `x-line-signature` ด้วย channel secret ก่อนแปลง JSON
2. รับเฉพาะข้อความส่วนตัวจาก `userId` ที่อยู่ใน allowlist; ไม่รับคำสั่งในกลุ่ม
3. ตัวกลางส่ง payload ไป Apps Script พร้อมเวลาและ HMAC ด้วย secret อีกชุด Apps Script ตรวจ HMAC, อายุคำขอ และ allowlist ซ้ำ
4. เก็บ LINE user ID และ webhook event ID ในคอลัมน์เพิ่มเติมของรายการเงิน เพื่อจำกัดคนยืนยันและป้องกันการสร้างร่างซ้ำเมื่อ LINE ส่ง webhook ซ้ำ
5. เก็บ secret ใน environment ของตัวกลางและ Script Properties ของ Apps Script เท่านั้น

## การยืนยันและกฎยอดเงิน

- คำสั่งสร้าง `DRAFT` ที่มี `source_type=LINE`; ไม่มีผลต่อยอดเงิน ลูกหนี้บริษัท หรือหนี้
- บอตตอบสรุปวันที่ ประเภท จำนวน บัญชี หมวด เจ้าของ รายละเอียด และรหัส; เจ้าของ LINE คนเดิมพิมพ์ `ยืนยัน <รหัส>` เพื่อบันทึกจริง
- การยืนยันทำภายใต้ `LockService` และใช้ `validateTx_`, การสร้างลูกหนี้บริษัท และการจับคู่เงินคืนเดิม; บันทึก Audit Log ระบุแหล่ง `LINE`
- รายการ LINE ที่ยังเป็นร่างยืนยันผ่านคำสั่ง LINE เท่านั้น ส่วน DRAFT จาก IMPORT และ WEB ยังใช้หน้าจอเดิม
- รายการซ้ำจาก webhook หรือคำสั่งยืนยันซ้ำต้องไม่บันทึกเงินซ้ำ
- ไม่รับสลิป รูปภาพ คำสั่งชำระหนี้ หรือรายการประจำในระยะนี้ เพราะแต่ละชนิดต้องตรวจรายละเอียดเพิ่มเติมก่อนลงบัญชี

## การเปิดใช้งาน

โค้ดพร้อมทดสอบในเครื่อง แต่การรับข้อความจริงต้องตั้งค่า LINE Messaging API, secret, user ID และโฮสต์ HTTPS สำหรับตัวกลาง ตาม `LINE-SETUP.md` การอัปเดต Apps Script อย่างเดียวไม่เปิด webhook
